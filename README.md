## 关于我

我喜欢把一个想法做成能跑的服务，也喜欢顺手把它背后的原理弄明白。

偏后端，偶尔做前端；关注工程落地，也保留一点对底层、性能和系统设计的好奇心。

> 写代码是工作，研究问题是习惯。

## 我在做什么

**01 · Build**　API、业务服务、自动化工具，以及能真正解决问题的小项目。

**02 · Connect**　把后端、浏览器、数据和部署连接起来，让系统少一点摩擦。

**03 · Research**　性能、运行时、搜索、基础设施，还有那些“为什么会这样”的问题。
